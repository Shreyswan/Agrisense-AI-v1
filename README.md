# Agrisense-AI-v1 🚀
This repository contains front-end as well as backend for a one stop product for farmers to know about their crops. It promotes smart agriculture in rural areas. 
It is easy to use and doesn't involve difficult to understand mechanics for operating the app.

### Core functionalities:💪
1. AI Chatbot 🤖: An LLM that's tuned for agriculture knowledge! It's ready to solve any doubt for the farmers and to help new farmers understand the processes involved in agriculture.
2. Crop diagnosis 🌾: This tool uses an Advance Deep Learning AI model (Siamese network) for predicting diseases in the crops based on a simple image provided as input.
3. Video Sharing 🎥: Sharing knowledge increses knowledge! This platform is for farmers to upload videos of their techniques of farming so that other farmers can learn from them and improve the yield. Thus helping the whole community grow and become prosperous together.

### Salient Features:🌟
1. User friendly UI with emphasis on colours and images/icons instead of texts.
2. Easy to use features with no extra knowledge required for using the app.
3. Phenomenal accouracy of ~90% on test data for the Siamese network. Along with that, due to use of Meta Learning, the model works efficiently on data that it has never encountered while training.
4. Efficiency combined with light form factor! the Siamese Net model is really light requiring very little storage thus making it available on lower end machines is possible.
5. Chatbot uses API of LLAMA3, thus making it really efficient at it's response.
